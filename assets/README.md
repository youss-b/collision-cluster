# assets/

`CollisionCluster.blend` lights its two worlds with HDRIs that live in this
folder. They're big (~96 MB together) and both are free CC0 downloads, so
they're not committed — grab them yourself and drop them in here.

The .blend links them by relative path, so **the filenames have to match
exactly**:

| file | where to get it |
| --- | --- |
| `NightSkyHDRI007_4K_HDR.exr` | [ambientCG — Night Sky HDRI 007](https://ambientcg.com/view?id=NightSkyHDRI007) — download the **4K HDR (EXR)** zip and pull this file out of it. |
| `white_home_studio_4k.exr` | [Poly Haven — White Home Studio](https://polyhaven.com/a/white_home_studio) — download **4K EXR**; it arrives with this name already. |

Both are CC0 (public domain), so you can use them for anything without
attribution. They're credited in the top-level README anyway.

If a world comes up pink in Blender, one of these is missing or misnamed.
